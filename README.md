# Калькулятор с поддержкой dll, язык: C++


### Основные Возможности
##Все операци реализованы через dll
##Базовые операции: Поддержка `+`, `-`, `*`, `/`.
##Функции плагинов: Встроенные плагины для `sin`, `cos`, `ln`, `pow`.
##Горячее Подключение/Отключение : Главное приложение не блокирует DLL-файлы, что позволяет добавлять новые плагины или удалять существующие во время работы программы.


### Инструкции по Сборке

Выполните следующие команды в терминале:

```
mkdir build
cd build

cmake .. 

cmake --build . --config Release

cd .\bin\Release
.\calc.exe
```
### Для проверки удаления и добавления dll файлов на runtime

Изменять ту папку './plugins', которая находится на одном уровне с calc.exe
